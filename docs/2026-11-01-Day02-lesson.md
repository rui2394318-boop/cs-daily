## Part 1 英语 25 分钟

### 1. 语音热身 3 min：三个高频错音

| 错在哪 | 典型读法 | 正确读法 | 最小对立 |
|---|---|---|---|
| /θ/ 读成 /s/ 或 /f/ | *think* → “sink” | 舌尖轻触上齿背送气，/θɪŋk/ | think /θɪŋk/ – sink /sɪŋk/ |
| /v/ 读成 /w/ | *very* → “wery” | 上齿咬下唇摩擦，/ˈveri/ | very /ˈveri/ – wary /ˈweəri/ |
| 词尾 /l/ 吞掉或卷成 /r/ | *seal* → “seo” / “sear” | 舌尖抵上齿龈，舌后部压低，/siːl/ | seal /siːl/ – sear /sɪə/ |

练习法：每组最小对立连读 5 遍（A-B-A-B），再放进短句：*Think about the seal very carefully.* 注意 /θ/ 送气要够、/v/ 要有摩擦、词尾 /l/ 舌尖别松太早。

### 2. 影子跟读 8 min

**稿 A：向供应商追问配方变更（约 45 秒）**

> Hi Mark, thanks for joining. We noticed the compression set on the last two lots moved up. I don't have the full picture yet, so I'd like to understand what changed. Could you walk me through the cure system on your side? I'm not saying anything is wrong — I just want to see whether the accelerator package was adjusted. If it was, that's fine; I only need to know so we can re-check our validation plan. Would it be possible to share the batch records by Friday?

发音点：
- *I'd like to* → /aɪd laɪk tə/，*to* 弱读为 /tə/。
- *what changed* 中 /t/ 与 /tʃ/ 相接，*what* 的 /t/ 几乎不除阻，直接滑入 changed。
- *walk me through* 连读 /wɔːk mi θruː/，*through* 的 /θr/ 要送气。
- *I'm not saying* 重音落在 **not** 与 **say**，语气放软靠降调而非加重。
- *Would it be possible* → /wʊd ɪt bi ˈpɒsəbl/，*it* 的 /t/ 浊化成闪音。

节奏：每句一个信息块，句末降调；委婉句（I'd like to / Would it be possible）语速略慢半拍。

**稿 B：内部评审会上质疑测试方法（约 40 秒）**

> One thing I'd like to clarify before we close: the compression set data — was it run at 70 hours or 24? I ask because the numbers look lower than what we saw last quarter. It might just be a different test duration, so I don't want to read too much into it. Could someone confirm the fixture and the platen size as well? That would help me compare apples to apples.

发音点：
- *One thing I'd like to* 整句连成一气，*thing* 的 /θ/ 别读成 /s/。
- *was it run* → /wəz ɪt rʌn/，*was* 弱读 /wəz/。
- *I ask because* 中 /k/ 与 /b/ 相接，不要加元音。
- *read too much into it* 连读 /riːd tuː mʌtʃ ˈɪntu ɪt/。
- *apples to apples* 重音对称，节奏感强，收尾干脆。

节奏：质疑句用升调收（was it run at 70 hours **or 24**↗），把“质问”变成“确认”。

### 3. 功能句 6 组：直接版 vs 委婉版

| 场景 | 直接版 | 委婉版 |
|---|---|---|
| 问配方为何改 | Why did you change the cure system? | Could you walk me through what changed in the cure system? |
| 问数据为何异常 | Why is the compression set so high? | I'd like to understand what's driving the compression set here. |
| 质疑测试条件 | Did you test at the wrong temperature? | Can I confirm which temperature the test was run at? |
| 要求解释偏差 | Explain this deviation. | It would help me to hear how you see this deviation. |
| 追问根因 | What's the root cause? | What's your read on the root cause so far? |
| 要求补数据 | Send me the batch records. | Would it be possible to share the batch records by Friday? |

规律：把 “Why…” 换成 “I'd like to understand / Could you walk me through / What's your read on…”，把责任句换成“我需要信息”句。

### 4. 词汇 12 个

| 词 | 音标 | 释义 | 搭配 |
|---|---|---|---|
| cure | /kjʊə/ | 硫化、固化 | cure system, cure state, under-cured |
| accelerator | /əkˈseləreɪtə/ | 促进剂 | accelerator package, accelerator level |
| crosslink | /ˈkrɒslɪŋk/ | 交联（点/密度） | crosslink density, crosslink network |
| compression set | /kəmˈpreʃn set/ | 压缩永久变形 | compression set value, CS at 70h |
| hardness | /ˈhɑːdnəs/ | 硬度 | Shore A hardness, hardness drift |
| plasticizer | /ˈplæstɪsaɪzə/ | 增塑剂 | plasticizer migration, plasticizer loss |
| antioxidant | /ˌæntiˈɒksɪdənt/ | 防老剂 | antioxidant loading, AO package |
| degradation | /ˌdeɡrəˈdeɪʃn/ | 降解、老化劣化 | thermal degradation, oxidative degradation |
| migration | /maɪˈɡreɪʃn/ | 迁移（小分子析出） | plasticizer migration, additive migration |
| tensile strength | /ˈtensaɪl streŋθ/ | 拉伸强度 | tensile retention, tensile at break |
| elongation | /ˌiːlɒŋˈɡeɪʃn/ | 断裂伸长率 | elongation at break, elongation retention |
| outgassing | /ˈaʊtɡæsɪŋ/ | 出气、挥发析出 | outgassing at high temperature, fogging |

**词根专栏：-cross- / -link-**
- *crosslink* = cross（交叉）+ link（连接）→ 交联。同族：crosslinked（交联的）、crosslinking agent（交联剂）、crosslink density（交联密度）。
- 反义/相关：*chain scission*（断链）—— 与交联相对，是老化后变软/发粘的主因。记住一对：**crosslink ↑ → 变硬变脆；chain scission ↑ → 变软发粘**。

### 5. 场景对话 4 min

A: Thanks for making time. We saw the compression set on lot 24-117 come in higher than usual.  
B: Sure — happy to look into it. Do you have the number in front of you?  
A: Yes, 38% at 70 hours, 100 °C. Last quarter we were around 28%.  
B: That's a meaningful jump. **I'd like to understand** whether the cure time was shortened on that run.  
A: Agreed. **Could you walk me through** what changed between the two lots?  
B: Off the top of my head, nothing on the recipe — but let me pull the batch record. **My read is** it might be a cure-time issue, not the formula.  
A: That would make sense. **Would it be possible** to get the cure curves by Friday?  
B: I'll send them over. And **just so I'm clear** — are you seeing hardness drift too, or only compression set?

地道表达标注：*come in higher than usual*（数值偏高）、*a meaningful jump*（明显跳变）、*off the top of my head*（凭印象）、*my read is*（我的判断）、*just so I'm clear*（确认一下）。

### 6. 输出任务 2 min

1. **录音**：用稿 B 做 60 秒影子跟读，录一遍；回听只查三件事——/θ/ 是否送气、*I'd like to* 是否连读、质疑句是否用升调收尾。
2. **写句子**：把下面 3 句直接版改写成委婉版，各写 1 句：
   - Why did the hardness go up after aging?
   - Did you use the wrong platen size?
   - Explain why the seal cracked.

## Part 2 产品专题 25 分钟：EPDM 配方与硫化——为什么会变硬、会开裂

### 1. 一句话定义与图纸位置

EPDM（Ethylene Propylene Diene Monomer，三元乙丙橡胶）密封条的“变硬、开裂”，本质是**交联密度与低分子组分（增塑剂、防老剂、挥发分）随热氧老化同时漂移**的结果：交联继续增加 → 变硬变脆；增塑剂迁移/挥发 → 收缩、变硬；两者叠加在动态弯折区（如车门密封条唇口、玻璃导槽转角）就表现为表面龟裂（surface cracking）乃至贯穿开裂。它在图纸上的位置不是单一尺寸，而是**材料规范 + 老化后性能保持率**：图纸标注材料牌号（如 EPDM Shore A 70）、硫化状态（cure state / fully cured），并在技术要求栏引用老化后硬度变化（Δhardness）与压缩永久变形（compression set）上限。

### 2. 怎么测

| 项目 | 标准号 | 设备/几何 | 试样 | 环境 | 读数与取值 |
|---|---|---|---|---|---|
| 硬度 | ISO 48-4 / ASTM D2240（Shore A） | Shore A 压头：截锥形，端面 Ø0.79 mm，35° 锥角，压足 Ø18 mm | 成品截面 ≥6 mm 厚，或叠层 | 23±2 °C，读数前接触 1 s（或 3 s，按规范） | 5 点取中位数，点间距 ≥6 mm、距边缘 ≥12 mm |
| 压缩永久变形 | ISO 815-1 / ASTM D395 Method B | 压缩夹具，压缩率 25% | 圆柱 Ø13×6.3 mm 或成品段 | 70 h @ 100 °C（或 24 h @ 70 °C） | 卸压后 30 min 内测厚度，CS=(t0−t1)/(t0−ts)×100% |
| 拉伸/伸长 | ISO 37 / ASTM D412 | 哑铃 1 型，500 mm/min | 2 mm 片 | 23±2 °C | 5 个试样中位数，断裂值剔除异常 |
| 热空气老化 | ISO 188 / ASTM D573 | 老化箱 | 同上 | 70 h/100 °C 或 168 h/100 °C | 老化后测 Δhardness、拉伸保持率 |
| 耐候/龟裂 | ISO 4665 / ASTM G154（氙灯/UV） | 氙灯箱 | 成品段 | 循环辐照+喷淋 | 目视评级（无裂纹/微裂/开裂） |

取值规则统一：**同一批至少 5 个试样，报中位数；老化前后必须同设备、同操作者、同读数时刻**，否则 Δhardness 不可比。

### 3. 参数族/标尺对比

| 参数 | 物理含义 | 升高意味着 | 降低意味着 | 常用标尺 |
|---|---|---|---|---|
| 交联密度 | 单位体积交联点数 | 变硬、变脆、CS 改善 | 变软、发粘、CS 变差 | 溶胀法/扭矩曲线 MH |
| Shore A 硬度 | 压入阻力 | 手感硬、贴合差 | 太软、易变形 | 40–80 Shore A |
| 压缩永久变形 CS | 卸载后残余变形 | 密封力衰减 | 回弹好 | 越低越好 |
| 拉伸强度 | 抗拉能力 | 抗裂好 | 易撕裂 | MPa |
| 断裂伸长率 | 延展性 | 柔韧 | 脆 | % |
| Δhardness（老化后） | 老化硬化程度 | 变硬开裂风险 | 软化发粘 | ±10 以内 |

### 5. 参数升/降的连锁影响

| 变化 | 直接性能 | 后果 |
|---|---|---|
| 交联密度↑ | 硬度↑、CS↓、伸长↓ | 装配压入力变大、低温变脆、弯折处易裂 |
| 交联密度↓ | 硬度↓、发粘 | CS 变差、密封力衰减、永久变形 |
| 增塑剂迁移/挥发 | 硬度↑、体积收缩 | 唇口贴合失效、表面龟裂 |
| 防老剂不足 | 氧化断链/交联并存 | 表面粉化、龟裂、颜色变化 |
| 硫化不足（under-cured） | CS 差、永久变形大 | 装配后压扁不回弹、漏水/漏风 |

### 6. 配方与设计杠杆

| 杠杆 | 调整方向 | 影响 | 注意 |
|---|---|---|---|
| 促进剂 package | 增/减、换快慢体系 | 硫化速度、交联密度 | 过快易焦烧（scorch） |
| 硫/过氧化物硫化体系 | 硫磺体系→过氧化物 | 耐热、CS 改善 | 过氧化物气味、成本 |
| 增塑剂类型/用量 | 高分子量、低迁移 | 减少硬化收缩 | 过量析出、污染 |
| 防老剂（AO） | 提高负载/复配 | 抗热氧老化 | 成本、变色 |
| 填料（炭黑） | 增加补强 | 强度↑、硬度↑ | 过多伸长下降 |
| 截面设计 | 唇口减薄、加筋 | 降低弯折应力 | 密封力需复核 |

### 7. 温度/时间/老化漂移

- **短期高温**：交联后硫化（post-cure）继续，硬度缓慢上升；增塑剂开始挥发。
- **长期热氧**：交联与断链竞争，表面先硬化龟裂，内部仍软——形成“硬壳软芯”，弯折时壳层开裂。
- **循环载荷+臭氧**：唇口应力集中处最先出现臭氧龟裂（ozone cracking），方向垂直于应力。
- **低温**：玻璃化转变附近变硬，回弹变差，装配后密封力不足。

### 8. 图纸与规范写法

```
材料: EPDM, 密实胶, Shore A 70 ±5 (ISO 48-4)
硫化: fully cured, 无欠硫 (cure state per ISO 3417 扭矩曲线 MH±5%)
老化后要求: 70h/100°C 热空气老化 (ISO 188)
  Δhardness ≤ +10 Shore A
  拉伸强度保持率 ≥ 80%
  断裂伸长率保持率 ≥ 70%
压缩永久变形: ≤30% (ISO 815-1, 70h/100°C, 25%压缩)
耐臭氧: 50 pphm, 40°C, 20%拉伸, 72h, 无裂纹 (ISO 1431-1)
表面: 无龟裂、无析出、无喷霜
```

### 9. 测量/应用陷阱

1. **硬度读数时刻不一致**：1 s 与 3 s 读数差 2–3 Shore A，老化前后必须同规则。
2. **成品叠层测硬度**：层间未压紧会读低，须用同厚度叠层或曲面适配压足。
3. **CS 卸载后测得太晚**：回弹仍在进行，超过 30 min 读数偏小。
4. **老化箱换气率不足**：挥发物累积，老化偏轻，Δhardness 偏小。
5. **只测新件不测老化件**：变硬开裂是老化现象，新件数据无法暴露风险。
6. **唇口取样位置随意**：转角/模压接头与挤出段性能不同，须分别取样标注。

### 10. 延伸到当前产品与技术方向

库博标准公开产品线中，**Fortrex**（轻量化密封材料体系）通过配方与结构降低重量同时保持密封性能，对配方端的交联与增塑体系平衡要求更高；**FlexiFit**（可变截面/柔性适配密封）强调唇口随车身公差自适应，对硬度与 CS 的稳定性敏感；**FlexiCore**（复合/中空结构密封）在减重的同时需控制老化后硬化对密封力的影响。方向一致：**配方（交联+防老+低迁移增塑）× 截面设计 × 老化后性能保持率**三者联动验证。

### 参考答案

**1. EPDM 密封条老化后“变硬”的主因是什么？**
交联密度继续上升（后硫化、热氧交联）叠加增塑剂迁移/挥发导致体积收缩，两者共同使硬度上升、伸长下降。

**2. 压缩永久变形测完后为什么必须在 30 min 内读数？**
卸载后试样仍在回弹，延迟读数会低估残余变形，使 CS 偏小、结果偏乐观。

**3. 图纸上“Δhardness ≤ +10”约束的是什么风险？**
约束老化硬化程度，间接控制变脆与唇口龟裂风险；超过则弯折区易开裂、密封力分布改变。

**4. 交联密度升高一定好吗？**
不是。CS 改善但硬度上升、伸长下降、低温变脆，装配压入力增大，弯折处应力集中反而易裂，需平衡。

**5. 为什么新件硬度合格仍可能出现开裂？**
开裂多由老化后硬化+臭氧+循环应力共同触发，新件数据不反映老化漂移；须做热空气老化与臭氧试验并测老化后性能保持率。
