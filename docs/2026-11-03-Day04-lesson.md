## Part 1 英语 25 分钟

### 1. 语音热身 3min：三个中国人常见错音

| 错在哪 | 典型读法 | 正确读法 | 最小对立 |
|---|---|---|---|
| **/ʃ/ 读成 /s/** | Shore 读成 "sore" /sɔːr/ | Shore /ʃɔːr/，起始舌叶抬向硬腭、唇略前突 | sore /sɔːr/ — shore /ʃɔːr/；sea /siː/ — she /ʃiː/ |
| **/θ/ 读成 /s/ 或 /f/** | thickness 读成 "sickness" | thickness /ˈθɪknəs/，舌尖轻触上齿背、送气不振动 | think /θɪŋk/ — sink /sɪŋk/；three /θriː/ — free /friː/ |
| **词尾 /t/ /d/ 吞掉或加元音** | set 读成 "seh" 或 "set-uh" | set /set/，词尾塞音做好口型、轻爆破或不爆破但不加元音 | set /set/ — sets /sets/；cold /koʊld/ — code /koʊd/ |

练习法：每个最小对立读 10 遍，先慢后快；录音回放，只听「起始音是否擦音化」「词尾是否多出一个元音」。

### 2. 影子跟读 8min：两段真实工作场景稿

**段 1：实验室读数汇报（约 40 秒）**

> "We ran the compression set per ASTM D395, Method B. Specimens are 13-millimeter diameter by 6.3-millimeter thick discs, stacked to reach a 12.5-millimeter compressed height. We compressed them 25 percent at 70 degrees Celsius for 22 hours, then let them recover for 30 minutes at room temperature. Average compression set came out at 28 percent — that's 3 points above the 25-percent limit."

发音点：
- **13-millimeter**：thirteen 重音在 -teen；millimeter 读 /ˈmɪləˌmiːtər/，四个音节不要压成三个。
- **6.3-millimeter**：读 "six point three millimeter"，point 的 /t/ 轻爆破。
- **25 percent**：读 "twenty-five percent"，percent 重音在 -cent。
- **70 degrees Celsius**：degrees 与 Celsius 之间连读 /dɪˈɡriːzk/；Celsius 读 /ˈselsiəs/，不是 "cel-see-us" 拖长。
- **22 hours**：读 "twenty-two hours"，hours 前有轻微 /j/ 滑音。
- 节奏：数字+单位是一个「重音节拍块」，块内连读、块间停顿。听自己是否在数字后停顿过长。

**段 2：设计评审对话（约 45 秒）**

> "The customer spec calls for Shore A 65 plus or minus 5, and a compression set under 30 percent after 70 hours at 100 degrees. Our current compound is marginal on set at elevated temperature, so I'd propose a higher-crosslink EPDM and re-run the 22-hour screening first."

发音点：
- **Shore A 65**：Shore 起始 /ʃ/；"sixty-five" 的 /ks/ 与 /f/ 相连，别读成 "sixty-five-uh"。
- **plus or minus 5**：整串连读为 /ˈplʌsərˈmaɪnəs/，or 弱读为 /ər/。
- **under 30 percent**：under 的 -er 弱读 /ər/；30 读 "thirty" /ˈθɜːrti/，注意 /θ/。
- **marginal on set**：marginal 与 on 连读 /ˈmɑːrdʒɪnəlɑːn/。
- **I'd propose**：I'd 的 /d/ 与 propose 的 /p/ 相遇，/d/ 几乎不爆破。
- 节奏：条件句（spec calls for…）语速快、降调；结论句（I'd propose…）放慢、重读 higher-crosslink 和 re-run。

跟读方法：先听一遍抓节奏块，第二遍跟读只做节奏（不管音准），第三遍补音准，第四遍录音对比。

**词根专栏：-set / -press-**
- **press**（压）→ compress（压缩）、compression（压缩）、compressive（压缩的）、compressor（压缩机）。记忆链：press → compress → compression → compression set，一条线串起「压—压缩—压缩量—压缩后残留变形」。
- **set** 在材料语境有两个义：① 永久变形/定型（compression set, tension set）；② 固化/定型（cure set）。看到 set 先判断是「变形残留」还是「固化」，别混。

### 5. 场景对话 4min

A: Can you walk me through the set result?
B: Sure. **We're at 28 percent** after 22 hours at 70 degrees — about 3 points over.
A: Is that **within the noise** of the test, or a real shift?
B: It's consistent across three specimens, so I'd call it **a real shift**.
A: What changed?
B: **The only variable is the cure time** — we shortened it by 10 percent last month.
A: Then let's **put the cure back** and re-run before we touch the compound.
B: Agreed. I'll **have the data by Thursday**.

地道表达：walk me through（带我把流程过一遍）、within the noise（在测量波动范围内）、a real shift（真实偏移）、the only variable is（唯一变量是）、put the cure back（把硫化时间改回去）、have the data by（在……之前拿到数据）。

2. **写 3 句**：各用一次 "plus or minus"、"under X percent"、"marginal on"。写完后朗读并标注重音。

## Part 2 产品专题 25 分钟：压缩永久变形 compression set

### 1. 一句话定义与图纸位置

**压缩永久变形（compression set）**：试样在规定温度下被压缩到规定变形量、保持规定时间，卸载并在规定条件下恢复后，**残留的不可恢复变形量占原压缩变形量的百分比**。它衡量密封材料在长期受压+受热后「还能不能弹回来」，直接决定密封力衰减与泄漏风险。

在图纸/规范上的位置：属于**材料性能要求（material callout）**，通常写在材料框或材料规格附注里，与硬度（hardness, Shore A）、拉伸强度（tensile strength）、撕裂强度（tear strength）、耐油/耐温（fluid/heat resistance）并列，形式如 "Compression set ≤ 25% (ASTM D395 Method B, 70 h @ 100 °C)"。它**不是**尺寸公差，不能画在尺寸链里；但它是密封截面（seal cross-section）设计的输入约束。

### 2. 怎么测

- **标准号**：ASTM D395（美系，最常用）、ISO 815（国际/欧系）。两者方法对应：D395 Method A ≈ ISO 815-1 恒定压缩量法；D395 Method B ≈ ISO 815-2 恒定压缩力法（实际工程中 Method B 更常用于密封胶料）。
- **设备/压头几何**：压缩夹具（compression fixture）由两块平行钢板 + 限位垫块（spacer）组成；Method A 用垫块把压缩量锁定在 25%（也可 15%/20%），Method B 用已知载荷把试样压到规定压缩应力。
- **试样**：标准为直径 13 mm ± 0.5 mm、厚 6.3 mm ± 0.3 mm 的圆盘（disc）；薄片可多层叠到规定厚度（stacked），叠层数要在报告中写明，因为层间摩擦会影响读数。试样表面平整、无气泡、无飞边。
- **环境**：规定温度（如 70 °C、100 °C、125 °C）的烘箱/老化箱，规定时间（22 h、70 h、168 h 常见）。温度均匀性直接影响结果。
- **读数方式**：卸载后按标准在规定恢复时间（通常 30 min，室温）内用厚度计（dial thickness gauge / digital gauge）测厚度，测点固定、轻放不压。
- **取值规则**：至少 3 个试样（常用 3–5 个），报**中位数或平均值**，同时报最大值与离散度；单值超限要复测。计算式：

```
Compression Set (%) = (t0 - t1) / (t0 - t2) × 100
t0 = 原始厚度 (original thickness)
t1 = 恢复后厚度 (thickness after recovery)
t2 = 垫块厚度 (spacer thickness, 即压缩后厚度)
```

### 3. 参数族/标尺对比表

| 参数 | 定义 | 与 compression set 的关系 |
|---|---|---|
| compression set（CS） | 压缩后残留变形百分比 | 核心指标，越低越好 |
| tension set | 拉伸后残留变形百分比 | 同族指标，反映同一交联网络弹性 |
| compression stress relaxation（CSR） | 恒压缩量下密封力随时间衰减 | 更贴近实际密封；CS 高通常 CSR 也差 |
| deflection | 受力下的压缩变形量 | 测试条件量，不是结果 |
| percent recovery | 卸载后恢复比例 ≈ 100% − CS | 同一数据的另一种说法 |

### 5. 参数升高/降低的连锁影响表

| 变化 | 直接性能后果 | 下游后果 |
|---|---|---|
| CS 升高 | 密封力衰减快、回弹差 | 漏水/漏风/异响（squeak & rattle）、NVH 变差、售后返修 |
| CS 升高 | 需更大初始压缩量补偿 | 关门力（closing effort）上升、装配困难 |
| CS 降低（过度交联） | 硬度上升、柔顺性下降 | 贴合性差、低温变硬、密封接触面减小 |
| CS 降低但伴随变脆 | 撕裂强度下降 | 装配/使用中开裂、耐久性风险 |

### 6. 配方与设计杠杆表

| 杠杆 | 方向 | 说明与代价 |
|---|---|---|
| 交联密度（crosslink density） | ↑ 降 CS | 最有效；过量则硬度↑、伸长率↓ |
| 硫化体系（cure system） | 调整促进剂/硫化剂比例 | 平衡 CS 与焦烧安全期（scorch safety） |
| 填料（filler） | 适量补强炭黑降 CS | 过量增硬、增压缩应力 |
| 增塑剂/油（plasticizer/oil） | ↓ 用量降 CS | 油在高温下挥发/迁移，长期反而升 CS |
| 聚合物选择 | 高饱和/高耐温胶（EPDM、VMQ、AEM） | 成本↑，但高温 CS 明显更优 |
| 截面设计 | 增大压缩量裕度、优化中空/唇形 | 补偿 CS，但增大关门力 |
| 后硫化（post-cure） | 二次硫化降 CS | 多一道工序、能耗↑ |

### 7. 温度/时间/老化导致的漂移

- **温度**：CS 随温度近似指数恶化。70 °C 合格不代表 100 °C 合格；规范必须写清温度，不能只写 "heat aged"。
- **时间**：22 h 是筛选（screening），70 h/168 h 才接近长期。短时数据外推长时要用阿伦尼乌斯（Arrhenius）思路，但需多温度点验证。
- **老化叠加**：热氧老化（heat aging）使交联继续或断链，CS 常先降后升；臭氧/紫外对表面裂纹影响大；油/介质接触引起溶胀（swell）与抽出（extraction），改变 CS。
- **实际工况**：连续压缩 + 温度循环 + 振动，比静态测试更苛刻，静态 CS 只能作相对排序。

### 8. 图纸与规范怎么写

```text
MATERIAL: EPDM, dense, 70 ± 5 Shore A (ASTM D2240)
COMPRESSION SET: ≤ 25% max
  TEST: ASTM D395 Method B
  SPECIMEN: 13 mm dia × 6.3 mm disc (stacked to 12.5 mm if needed)
  CONDITION: 25% deflection, 70 h @ 100 °C
  RECOVERY: 30 min @ 23 ± 2 °C
  REPORT: median of 3 specimens, plus max value
ALSO REQUIRED: tensile ≥ 8 MPa, elongation ≥ 250%, tear ≥ 20 kN/m
HEAT AGING: 70 h @ 100 °C, Δ hardness ≤ +10 Shore A, Δ tensile ≤ -20%
```

要点：标准号+方法+温度+时间+压缩量+恢复条件+取样规则，六项缺一不可；不要只写 "low compression set"。

### 9. 测量/应用陷阱

1. **恢复时间不统一**：30 min 与 1 h 读数差异可达数个百分点，必须按标准统一。
2. **叠层试样层间滑移**：叠层数变化导致读数漂移，报告须注明层数。
3. **厚度计压紧力过大**：测恢复厚度时压扁试样，读数偏小、CS 偏大。
4. **烘箱温度不均**：靠近加热元件位置温度偏高，同批试样离散大。
5. **只测 22 h 就下结论**：短时筛选通过不等于长期合格，高温件尤其危险。
6. **忽略介质影响**：实际接触油/水/清洗剂时 CS 与干态差异大，需做介质后 CS。

### 10. 延伸到当前产品与技术方向

密封系统的趋势是「**更低 CS + 更轻 + 更好贴合**」。库博标准公开产品线中，**Fortrex** 轻量化密封材料体系强调降低重量同时保持密封性能，对材料 CS 与压缩力平衡提出更高要求；**FlexiFit** 类柔性/可变截面密封方案通过截面与结构设计补偿材料 CS 衰减；**FlexiCore** 类复合/骨架结构则影响压缩力分布与长期回弹。工程含义：单靠配方降 CS 已接近极限，需「材料 + 截面 + 工艺」三线并进，并用 CSR 数据替代单一 CS 值做设计输入。

### 自测 5 题

1. 写出 compression set 的计算公式，并说明 t0、t1、t2 各是什么。
2. ASTM D395 Method A 与 Method B 的核心区别是什么？密封胶料常用哪个？
3. 为什么 22 h @ 70 °C 合格不能直接推断 70 h @ 100 °C 合格？
4. 列出三个会人为把 CS 读数做大的操作陷阱。
5. 图纸上写 "low compression set" 为什么不合格？应补齐哪六项？

### 参考答案

1. CS(%) = (t0 − t1)/(t0 − t2) × 100。t0 为原始厚度（original thickness），t1 为卸载恢复规定时间后的厚度（thickness after recovery），t2 为垫块/限位厚度即压缩后厚度（spacer thickness）。分子是残留变形，分母是实际施加的压缩变形量。
2. Method A 是**恒定压缩量法**（constant deflection，用垫块锁定如 25% 压缩量）；Method B 是**恒定压缩力法**（constant force，用已知载荷压缩）。密封胶料工程中更常用 Method B，因为它更接近密封件实际「受恒定夹紧力」的工况；Method A 更便于横向比较材料。
3. 因为 CS 对温度近似指数敏感、对时间也单调恶化。70 °C/22 h 只是低温短时筛选，交联网络在 100 °C 下会继续后硫化或断链，CS 显著上升；时间从 22 h 到 70 h 也叠加老化。必须用目标温度与目标时长（或至少多温度点做 Arrhenius 外推验证）才能下结论。
4. ①恢复时间不足或各试样不统一就读数；②厚度计压紧力过大把试样压扁；③叠层试样层数不一致或层间滑移；④烘箱温度不均导致局部过热；⑤试样有气泡/飞边未剔除。任答三个即可。
5. 因为 "low" 无量化、无测试条件、无取样规则，供应商可各自解释，无法验收。应补齐六项：标准号+方法（ASTM D395 Method B）、温度、时间、压缩量（25% deflection）、恢复条件（30 min @ 23 °C）、取样与报告规则（3 件中位数+最大值）。
