6 个最容易用错的词：

  1. compression set — 别直译成"压缩设置"。The compression set came back at 28%, which is above the 25% limit. 中国人常错：把 set 理解成"设定"，说成 "the compression set is set at…"。
  2. ageing — 材料领域是"老化"，不是"年龄增长"。We ran a heat ageing test at 100°C for 72 hours. 常错：说成 "oldening" 或 "aging test" 却念成 /ˈeɪdʒɪŋ/ 之外的怪音。
  3. tolerance — 工程里是"公差"，不是"容忍"。The dimension is outside tolerance by 0.2 mm. 常错：说 "the tolerance is too big" 想表达"公差太大"，但听起来像"容忍度太大"。
  4. specimen — 重音在第一音节 /ˈspesɪmən/。Please prepare five specimens for the ozone test. 常错：念成 /speˈsɪmən/，法国老板会愣一下。
  5. on mute — 不是 "in mute" 也不是 "close the mute"。Sorry, you were on mute — could you repeat that? 常错：说 "your microphone is closed"。
  6. lag — 视频卡顿用 lag，不用 delay。There's a bit of a lag on your side. 常错：说 "the internet is slow"，虽然能懂但不够地道。

Part 3 连词与连接词 6 个（4 分钟）

连词 作用 例句 中国人常犯的错
however 转折（书面/正式口语） The hardness is fine. However, the compression set is too high. 放句首后忘加逗号；或和 but 连用成 "but however"。
whereas 对比两件事 Shore A is 70, whereas the target was 75. 用成 "whereas" 代替 "because"，逻辑反了。
therefore 因果（正式） The ozone test failed; therefore, we need a new compound. 口语里过度使用，听起来像念论文。日常说 so 更自然。
as long as 条件（只要） As long as the specimen is conditioned, the result will be reliable. 说成 "as long as" 表"只要时间够长"，歧义。
unless 除非 We can't ship unless the ageing test passes. 后面误加 will：unless it will pass（错）。
due to 因为（后接名词） The delay is due to a problem with the test chamber. 接句子：due to we had a problem（错），应接名词短语。

3 句串成一段连贯汇报：

The ozone test passed and the hardness is within spec. However, the compression set came back at 28%, which is above our 25% limit. Therefore, I'd suggest we run one more ageing test before we confirm the compound.

Part 4 法国口音听力训练（8 分钟，重点）

4.1 法国人说英语的发音特征

特征 他会说成 你要听成 例子
h 音脱落（词首 h 不发音） 'ardness / 'ave hardness / have "the 'ardness is too 'igh" = the hardness is too high
th 变 s/z sink / zis think / this "I sink zis is a problem" = I think this is a problem
词尾重音（重音后移） compreSSION / paraMETER COMpression / paRAMeter "the paraMETER is wrong" = the parameter is wrong
/r/ 小舌音（法语 r） pwoblem 带喉音 r problem "we 'ave a pwoblem" = we have a problem
/ɪ/ 与 /iː/ 不分 sheep = ship ship / sheep 靠上下文 "the sheet is ready" 可能是 "the shit…"（笑点）→ 实际是 sheet
-ing 读成 -ingg meetingg / testingg meeting / testing "during the testingg" = during the testing
v / w 混淆 wery / veek very / week "it's wery difficult" = it's very difficult
词尾辅音吞掉或加重 tes / repord test / report "the tes is finish" = the test is finished
数字读法 fifteen / fifty 易混 fifteen (15) / fifty (50) "seventy-fifteen" 其实想说 75 → 让他拼出来

4.2 三个高频句的「他说的 → 你听的」

句 1： "I think we have a problem with the hardness on the B-pillar."
- 他大概会说："I sink we 'ave a pwoblem wiz ze 'ardness on ze B-pillar."
- 还原方法：sink→think，'ave→have，wiz→with，ze→the，'ardness→hardness。听到 "B-pillar" 就知道是车身件，锁定"硬度有问题"。

句 2： "The compression set is fifty percent — that's too high."
- 他大概会说："Ze compreSSION set is fifty perCENT — zat's too 'igh."
- 还原方法：fifty 和 fifteen 最容易混。听到 "perCENT" 重音后移别慌；如果数字关键，直接问 "Sorry — fifteen or fifty?"。

句 3： "Can you share your screen and run through the ageing results?"
- 他大概会说："Can you share your screen and run srough ze ageing resulTs?"
- 还原方法：srough→through，ze→the，resulTs 词尾 t 加重。听到 "share screen" + "ageing" 就明白要共享屏幕讲老化数据。

4.3 假朋友（faux amis）

他会用的词 他其实想表达 你要怎么理解
actually 法语 actuellement = 目前、当前 理解为 "at the moment / currently"，不是"实际上"
eventually 法语 éventuellement = 可能、也许 理解为 "possibly / maybe"，不是"最终"
assist 法语 assister à = 出席、参加 理解为 "attend"，不是"协助"
delay 法语 délai = 期限、时限 理解为 "deadline / timeframe"，不是"延迟"
control 法语 contrôle = 检查、检验 理解为 "check / inspection"，不是"控制"
sensible 法语 sensible = 敏感 理解为 "sensitive"，不是"明智"

4.4 一段模拟对话

老板： "OK, so let's start wiz ze ozone tes. 'Ow did it go?"（How did it go?）

你： Sorry, you cut out for a second — could you say that again?

老板： "I said, 'ow did ze ozone tes go?"（How did the ozone test go?）

你： Got it. The ozone test passed — no cracking after 72 hours.

老板： "Good. And ze compreSSION set?"（compression set）

你： Sorry, I didn't quite catch the number you mentioned earlier — was it fifteen or fifty?

老板： "Fifty. Fifty perCENT."

你： OK, fifty percent — that's above our limit. Let me share my screen and run through the data.

老板： "Yes, please. Your screen is — 'ow do you say — lagging a bit."

你： I see the lag too. Let me stop sharing and restart — can you still hear me?

老板： "Yes, I can 'ear you now. Go ahead."

Part 5 输出任务（2 分钟）

任务 1（开口录音）： 录一段 40 秒的语音，模拟会上没听清老板的话。念下面三句，注意语调自然、别像背书：

"Sorry, you were on mute — could you repeat that? … Thanks. Just to confirm — you said fifty percent compression set, not fifteen, correct? … OK, got it. Let me share my screen and run through the ageing results."

检查点：① 三句都念完，没有卡壳超过 2 秒；② "fifty / fifteen" 你自己念得清楚能区分；③ 录音回放时，能听出你在"确认"而不是"复述"。

任务 2（写）： 用 3–5 句英文写一段会议小结发给老板，必须包含：一个测试结果（用上 hardness / compression set / ozone 中至少两个）、一个 however 或 therefore、一个下一步动作。
检查点：① 至少两个今日词汇用对；② 有一个连词用得恰当；③ 有明确的 next step（谁、做什么、什么时候）。写完自己读一遍，能一口气念顺就算过。
