## Part 1 英语 25 分钟

### 1. 语音热身 3 min：三个中国人常见错音

**纠音目标：/θ/ /ð/、/v/、词尾 /l/ 与 /r/ 的区分。** 这三个音位在中文里没有对应音位，靠"口型记忆"最容易固化错误。

| 错在哪 | 典型读法 | 正确读法 | 最小对立 |
|---|---|---|---|
| /θ/ 舌尖没伸出来，读成 /s/ 或 /f/ | *think* → "sink"；*three* → "free" | 舌尖轻触上齿背、送气不振动声带 | think / sink；three / free；thick / sick |
| /ð/ 读成 /d/ 或 /z/ | *the* → "de"；*weather* → "weazer" | 舌尖轻触上齿背、声带振动、气流从舌齿间挤出 | they / day；breathe / breed；weather / weazer（错）vs. weather |
| /v/ 上齿不咬下唇，读成 /w/ | *value* → "walue"；*very* → "wery" | 上齿轻咬下唇、摩擦送气 | very / wary；vest / west；vent / went |
| 词尾 /l/ 吞掉或卷成 /r/ | *seal* → "seo" / "sear"；*control* → "contro" | 舌尖抵上齿龈、舌后部抬起，保持到词尾 | seal / sear；tool / tour；pool / poor |

练法：每个最小对立对连读 5 遍，先慢后快；/θ/ /ð/ 对着镜子确认舌尖可见。

## Part 2 产品专题 25 分钟：硬度 durometer 全解

### 1. 一句话定义与图纸位置

**硬度（hardness / durometer）** 是弹性体抵抗压头局部压入的能力，工程上用邵氏硬度（Shore A / Shore D）表示，无量纲。它在图纸上的位置：**材料标注行（material callout）**，紧跟材料标准号之后，例如 "EPDM, ASTM D2000 M2AA 610 A13 B13 C12 Z1 Z2 Z3, **Shore A 70 ±5**"。硬度不是孤立参数——它和拉伸强度、压缩永久变形、耐低温一起构成材料规格块，图纸上通常以"硬度 + 公差带"给出，而不是单点值。

### 2. 怎么测

- **标准号**：邵氏 A/D 用 **ASTM D2240**（对应 ISO 7619-1、GB/T 531.1）；国际橡胶硬度 IRHD 用 ISO 48-2。汽车密封件以 Shore A 为主。
- **设备与压头几何**：Shore A 压头为**截锥形**（truncated cone），端面直径 0.79 mm，锥角 35°，压足（presser foot）孔径 3 mm；Shore D 为 30° 锥、尖端半径 0.1 mm。弹簧力：Shore A 为 0.55–8.05 N（对应 0–100 刻度）。
- **试样**：厚度 ≥6 mm（不足可叠层，最多 3 层，总厚 ≥6 mm）；面积足够压足落座，距边缘 ≥12 mm；表面平整、无脱模剂残留。
- **环境**：标准实验室 23±2 °C、50±5 %RH；试样在测试前**状态调节（conditioning）** ≥1 h（薄件）至 16 h（厚件/仲裁）。
- **读数方式**：压足贴合试样后**1 s 内**读数（瞬时值，用于产线快检）；仲裁用 **15 s 后**读数（延迟值，蠕变稳定）。同一试样测 **5 点**，点间距 ≥6 mm、距边缘 ≥12 mm。
- **取值规则**：取 **5 点的中位数（median）**；若任一点与中位数偏差 >5 个单位，补测并剔除异常点。报告须写明"1 s 或 15 s"、"Shore A"、试样厚度与叠层数。

### 3. 标尺对比表

| 标尺 | 压头 | 适用材料 | 量程建议 | 备注 |
|---|---|---|---|---|
| Shore A | 截锥 35°，端面 0.79 mm | 软质橡胶、TPE、海绵表皮 | 20–90 A | 密封条主用 |
| Shore D | 锥 30°，尖端 R0.1 mm | 硬塑料、硬橡胶、玻纤增强 | 40–90 D | 硬质导槽/骨架包覆 |
| Shore 00 | 球头 | 超软凝胶、发泡 | 0–90 00 | 海绵密封条 |
| IRHD（M 法） | 球压头 | 橡胶，仲裁用 | 30–95 IRHD | 与 Shore A 近似但不完全等价 |

注意：Shore A 与 Shore D 在 90 A / 40 D 附近有重叠带，跨标尺换算不可直接套公式，须实测对照。

### 4. 典型值表（工程参考，非规范）

| 部位 | 材料 | 典型 Shore A | 说明 |
|---|---|---|---|
| 车门密封条密实胶（dense rubber） | EPDM | 65–75 | 主密封唇 |
| 门框密封条海绵胶（sponge） | EPDM 发泡 | 25–40（Shore 00/低 A） | 压缩载荷低 |
| 玻璃导槽（glass run channel） | TPE / EPDM | 60–75 | 耐磨 + 低摩擦涂层 |
| 行李箱密封条 | EPDM | 60–70 | — |
| 静态密封垫（static gasket） | NBR / EPDM | 70–80 | 压缩永久变形优先 |
| 硬质包覆/骨架 | PP + 玻纤 / 硬 TPE | 40–60 Shore D | 结构件 |

### 5. 硬度升高/降低的连锁影响

| 变化 | 性能影响 | 后果 |
|---|---|---|
| 硬度↑ | 压缩载荷（CLD）↑、抗压入↑、耐磨↑ | 关门力（door closing effort）↑、密封贴合变差、异响风险↑ |
| 硬度↑ | 低温变硬更明显 | 低温密封失效、脆裂风险 |
| 硬度↓ | 柔软贴合好、关门力↓ | 压缩永久变形↑、抗蠕变↓、易被挤出（extrusion） |
| 硬度↓ | 海绵胶过度软 | 支撑不足、密封唇塌陷、风噪/水密性下降 |
| 硬度批次漂移 | 同一零件密封力不一致 | 装配节拍波动、客户抱怨"关门手感不一致" |

### 6. 配方与设计杠杆

| 杠杆 | 方向 | 副作用 |
|---|---|---|
| 炭黑（carbon black）填充量↑ | 硬度↑、强度↑ | 伸长率↓、低温性能↓、密度↑ |
| 增塑剂/油（plasticizer/oil）↑ | 硬度↓、柔软 | 迁移析出、压缩永久变形↑、雾化（fogging） |
| 交联密度（cure state）↑ | 硬度↑、set↓ | 加工窗口变窄、焦烧风险 |
| 发泡倍率↑（sponge） | 表观硬度↓、密度↓ | 强度↓、吸水↑ |
| 壁厚/截面设计 | 等效刚度变化 | 硬度不变但密封力变——注意区分"材料硬度"与"结构刚度" |

### 7. 温度/时间/老化导致漂移

- **温度**：橡胶硬度随温度升高而下降，EPDM 在 −30 °C 附近显著变硬（低温硬化），是冬季关门力抱怨的常见根因。
- **老化**：热氧老化通常使硬度**上升**（后硫化/氧化交联），而增塑剂迁移/抽出会使硬度**上升**（变硬发脆）或局部下降。
- **压缩永久变形**：长期压缩下密封唇厚度减薄，等效密封力下降——硬度读数可能不变，但**功能已漂移**，所以硬度必须与 CLD、compression set 联合评估。
- **湿热/臭氧**：表面龟裂，硬度局部上升，属失效前兆。

### 8. 图纸与规范怎么写

```text
MATERIAL: EPDM per ASTM D2000 M2AA 610 A13 B13 C12 Z1 Z2 Z3
HARDNESS: Shore A 70 ±5 (ASTM D2240, 15 s delay reading,
          5-point median, specimen thickness >= 6 mm,
          conditioned 23±2 °C / 50±5 %RH for >= 16 h)
TEST FREQ: 1 specimen per lot; 5 readings per specimen
ACCEPT: median within 65-75 Shore A; no single reading
        deviating > 5 units from median without re-test
```

要点：**写标尺 + 数值 + 公差 + 标准号 + 读数方式（1 s/15 s）+ 取值规则 + 状态调节**，六项缺一不可，否则供应商与实验室各测各的。

### 9. 测量陷阱（5–6 个）

1. **叠层测薄件**：叠层界面引入额外柔度，读数偏低；仲裁必须单层 ≥6 mm。
2. **1 s 与 15 s 混用**：同一批数据混读导致 2–4 个单位偏差，误判超差。
3. **压足未完全落座**：曲面/带纹理表面，压足悬空，读数虚高。
4. **试样未状态调节**：刚下线零件余温使硬度偏低，误判"偏软"。
5. **跨标尺换算**：Shore A 与 D、IRHD 不能套公式，必须实测。
6. **只测材料不测结构**：硬度合格但截面设计导致密封力不合格，把结构问题误判为材料问题。

### 10. 延伸到当前产品与技术方向

库博标准（Cooper Standard）公开产品线中，**Fortrex** 是轻量化密封材料体系（以热塑性弹性体/发泡复合为主），其硬度设计需在**低密度、低压缩载荷**与**耐磨/耐候**之间平衡；**FlexiFit** 系列强调可变截面/柔性贴合，硬度沿截面分布（dense + sponge 复合）是关键；**FlexiCore** 涉及芯部结构与刚度的协同，硬度与结构刚度必须分开管控。工程含义：**硬度不是单点指标，而是"材料硬度—截面刚度—密封力—关门力"链条的起点**，任何硬度变更都要做 CLD 与整车关门力验证。

### 11. 自测 5 题

1. Shore A 的压头几何是什么？为什么薄件不能随便叠层测？
2. ASTM D2240 中 1 s 读数与 15 s 读数分别用于什么场景？取值规则是什么？
3. 硬度从 70 A 升到 78 A，最可能带来哪两个整车层面的后果？
4. 图纸上硬度标注必须包含哪六项信息？
5. 为什么"硬度合格"不能证明密封功能合格？请从 CLD 与 compression set 角度说明。

### 参考答案

1. Shore A 压头为截锥形，端面直径 0.79 mm、锥角 35°，压足孔径 3 mm。薄件叠层会在层间引入额外柔度，使压入更容易、读数偏低；且层间界面不一致导致重复性差，所以仲裁要求单层厚度 ≥6 mm，叠层仅作应急且须在报告中注明层数。
2. 1 s 读数用于产线快检/瞬时值，反映零件刚下线状态；15 s 读数用于仲裁与规范符合性，反映蠕变稳定后的延迟值。取值规则：同一试样测 5 点（点距 ≥6 mm、距边缘 ≥12 mm），取中位数；单点偏离中位数 >5 个单位须补测并剔除异常点。报告必须写明用的是 1 s 还是 15 s。
3. 硬度升高使压缩载荷（CLD）升高、抗压入与耐磨提高，但直接后果是：①关门力（door closing effort）上升，客户手感变差、装配节拍受影响；②低温硬化更明显，冬季密封贴合变差、异响/水密风险上升；同时压缩永久变形可能改善，但挤出（extrusion）风险随刚度上升而改变，需整体验证。
4. 标尺（Shore A/D）、数值、公差带、标准号（ASTM D2240）、读数方式（1 s 或 15 s）、取值规则（5 点中位数、异常点处理）；严格说还应加状态调节条件与试样厚度要求，工程上常合并为"六项 + 调节条件"。
5. 硬度只反映材料抗压入能力，不反映截面在压缩下的实际反力。密封功能取决于 CLD（压缩载荷）与 compression set（压缩永久变形）：硬度合格但截面壁厚/形状变化会使 CLD 偏离设计值；长期压缩后 set 增大、密封唇减薄，等效密封力下降，而硬度读数可能不变。因此硬度必须与 CLD、compression set、整车水密/风噪/关门力联合验证，才能判定功能合格。
