## Part 1 英语 25 分钟

### 1. 语音热身 3min：三个高频错音

| 错在哪 | 典型读法（错） | 正确读法 | 最小对立（minimal pair） |
|---|---|---|---|
| /θ/ 读成 /s/ 或 /f/ | *think* → "sink"；*three* → "free" | 舌尖轻触上齿背、送气不振动声带：/θɪŋk/、/θriː/ | think /θɪŋk/ – sink /sɪŋk/；three /θriː/ – free /friː/ |
| /v/ 读成 /w/ | *very* → "wery"；*valve* → "walve" | 上齿轻咬下唇、声带振动：/ˈveri/、/vælv/ | very /ˈveri/ – wary /ˈweəri/；vest /vest/ – west /west/ |
| 词尾 /l/ 吞掉或读成 /o/ | *seal* → "seo"；*tool* → "too" | 舌尖抵上齿龈、舌后部略抬，保持到词尾：/siːl/、/tuːl/ | seal /siːl/ – see /siː/；tool /tuːl/ – too /tuː/ |

练法：每个最小对立读 5 遍，第 1 遍慢速夸张，第 2 遍正常语速；录音回放，只听"是否区分得开"，不管口音。

### 2. 影子跟读 8min：两段工作场景稿

**Passage A — 图纸评审会开场（约 40 秒）**

> Good morning, everyone. Thanks for joining the design review. Today we'll walk through the weatherstrip **profile** /ˈproʊfaɪl/ for the new SUV program. First, I'll cover the **sealing** /ˈsiːlɪŋ/ requirements, then the **durometer** /dʊˈrɑːmɪtər/ callouts, and finally the open issues. Please hold questions until the end of each section, and if something is **blocking** /ˈblɑːkɪŋ/ your work, flag it right away.

发音点：
- *walk through* → /wɔːk θruː/，/k/ 与 /θ/ 相接，/k/ 只做口型不出声（不完全爆破）。
- *hold questions* → /hoʊld ˈkwestʃənz/，/d/ + /k/ 时 /d/ 弱化，几乎听不见。
- *until the end* → /ənˈtɪl ði ˈend/，*the* 在元音前读 /ði/。
- 连读：*cover‿it*、*flag‿it* 词间加轻微 /j/ 滑音。
- 节奏：每句重音落在 **re-view / profile / SEAL-ing / DU-rom-eter / BLOCK-ing**，其余压缩。

**Passage B — 供应商电话（约 35 秒）**

> Hi Mark, it's Lin from Cooper Standard. I'm calling about the EPDM **compound** /ˈkɑːmpaʊnd/ you shipped last week. The **hardness** /ˈhɑːrdnəs/ came in at 72 Shore A, but our spec is 68 plus or minus three, so it's **borderline** /ˈbɔːrdərlaɪn/. Could you pull the **batch** /bætʃ/ records and check the cure time? We'd like a **corrective action** /kəˈrektɪv ˈækʃn/ by Friday.

发音点：
- *it's Lin* → /ɪts lɪn/，/ts/ 连读成一个塞擦音。
- *came in at* → /keɪm‿ɪn‿æt/，三词连读，/m/ 与 /ɪ/ 自然衔接。
- *plus or minus* → /plʌs ər ˈmaɪnəs/，*or* 弱读为 /ər/。
- *would like* → /wʊd laɪk/，/d/ 与 /l/ 同化，听起来像"wull-like"。
- 节奏：数字 **72 / 68 / three** 重读放慢，其余连成一串。

跟读方法：先盲听 1 遍抓大意 → 看稿跟读 2 遍（落后原声 1–2 词）→ 脱稿复述 1 遍。

## Part 2 产品专题 25 分钟：硬度 durometer 全解

### 1. 一句话定义与图纸位置

**硬度（hardness / durometer）** 是密封条胶料抵抗压头局部压入的能力，工程上以 **邵氏 A（Shore A）** 标尺表示，是无量纲数值。在图纸上它出现在**材料标注（material callout）** 或**技术要求注释（general notes）** 里，通常写成 `EPDM, 70 ± 5 Shore A, per ASTM D2240`，与密度、拉伸强度、压缩永久变形并列，属于**材料性能项**，不是尺寸项。

### 2. 怎么测

| 项目 | 内容 |
|---|---|
| 标准号 | ASTM D2240（美标）／ISO 868（国际）／GB/T 531.1（国标），三者方法一致 |
| 设备 | 邵氏 A 型硬度计（durometer, Type A），弹簧加载 |
| 压头几何 | 截头圆锥，端面直径 0.79 mm，锥角 35°，顶端圆角 R0.1 mm |
| 试样 | 厚度 ≥6 mm；薄件可叠层（stacking），最多叠至 6 mm；表面平整、无缺陷 |
| 环境 | 标准实验室 23±2 °C、50±5 % RH；试样状态调节 ≥1 h（ISO 推荐 16 h 更稳） |
| 读数方式 | 压头垂直压紧、与试样完全接触，**1 秒内读瞬时值**（instantaneous）或 **15 秒读延迟值**，两者不可混用，报告须注明 |
| 取值规则 | 同一试样测 **5 点**，点间距 ≥6 mm、距边缘 ≥12 mm，取**中位数**（median）；极差超 5 需复测 |

关键：硬度计是**相对测量**，每日开机须用**标准硬度块（reference block）** 校准，偏差 >1 单位即停用。

### 3. 标尺对比表

| 标尺 | 适用材料 | 压头 | 典型范围 | 备注 |
|---|---|---|---|---|
| Shore A | 软胶、弹性体 | 圆锥钝头 | 20–90 | 密封条主用 |
| Shore D | 硬塑料、硬胶 | 圆锥尖头 | 40–90 | 与 A 不通用 |
| Shore 00 | 超软胶、海绵 | 球头 | 20–90 | 海绵密封条用 |
| IRHD | 橡胶（国际硬度） | 球压头 | 30–90 | 与 Shore A 近似但不可互换 |
| 邵氏 A 与 D 重叠区 | — | — | A90 ≈ D40 | 只作参考，不作换算依据 |

### 4. 典型值表（工程参考，非规范）

| 部位 | 材料 | 典型 Shore A |
|---|---|---|
| 车门密封条密实胶（dense rubber） | EPDM | 65–75 |
| 玻璃导槽（glass run）唇口 | EPDM / TPV | 60–70 |
| 海绵泡管（sponge bulb） | EPDM 发泡 | 25–40（或用 Shore 00） |
| 内饰亮条包边（trim lip） | TPV / PVC | 70–85 |
| 硬质骨架（carrier） | PP / 金属 | 不测 Shore A，测 Shore D 或不计 |
| Fortrex 类轻量化密实胶 | 专有配方 | 55–70 |

**以上为行业常见区间，仅供估算，实际以图纸与材料规范为准。**

### 5. 硬度升高/降低的连锁影响

| 变化 | 直接性能 | 后果 |
|---|---|---|
| 硬度↑ | 压缩负荷（CLD）↑、密封力↑ | 关门力（door closing effort）↑、异响风险↑、装配困难 |
| 硬度↑ | 耐磨↑ | 但柔顺性↓，贴合曲面能力↓，易渗水 |
| 硬度↓ | 压缩永久变形可能↑（视配方） | 长期密封力衰减、老化后渗漏 |
| 硬度↓ | 柔顺性↑、贴合好 | 但抗撕裂↓、挤出易变形、尺寸稳定性↓ |
| 硬度波动（批间） | 装配一致性↓ | 线束/工装需反复调，客户投诉 |

### 6. 配方与设计杠杆

| 杠杆 | 方向 | 说明 |
|---|---|---|
| 炭黑（carbon black）用量↑ | 硬度↑ | 最直接的补强手段，过量影响弹性 |
| 增塑剂/油（plasticizer/oil）↑ | 硬度↓ | 但易迁移、老化后硬度回升 |
| 交联密度（cure density）↑ | 硬度↑ | 与硫化体系、促进剂相关 |
| 填料（白炭黑、碳酸钙） | 硬度↑ | 成本与性能权衡 |
| 发泡倍率（sponge）↑ | 硬度↓ | 泡管专用 |
| 断面设计（壁厚、空腔） | 表观刚度变化 | 不改胶料也能调密封力 |

### 7. 温度/时间/老化漂移

- **温度**：橡胶硬度随温度升高而下降（典型 -0.5～-1 Shore A / 10 °C），低温则变硬。低温下密封条变硬是**关门力冬季升高**的主因。
- **老化**：热氧老化后增塑剂挥发/迁移，硬度通常**上升 3–8 单位**（70 h @ 100 °C 后常见）；压缩永久变形同步恶化。
- **时间**：未硫化胶存放会自然硬化；成品长期受压部位出现"硬化 + 永久变形"复合劣化。
- 结论：图纸硬度是**初始值**，需配套**老化后硬度变化限值**（如 Δ≤+8 Shore A）。

### 8. 图纸与规范怎么写

```
MATERIAL: EPDM, dense
HARDNESS: 70 ± 5 Shore A
TEST METHOD: ASTM D2240, Type A, 1 s instantaneous reading
SPECIMEN: finished seal section, thickness ≥ 6 mm (stack if needed)
READINGS: 5 points, median reported; range ≤ 5
CONDITIONING: 23 ± 2 °C, 50 ± 5 % RH, ≥ 16 h
AGING: 70 h @ 100 °C per ASTM D573; hardness change ≤ +8 Shore A
CALIBRATION: reference block check before each session, deviation ≤ 1 unit
```

要点：**标尺 + 数值 + 公差 + 方法 + 读数方式 + 试样 + 老化要求**，七项缺一不可。

### 9. 测量与应用陷阱

1. **薄件直接测**：厚度 <6 mm 不叠层，读数偏高且离散大。
2. **瞬时值 vs 15 秒值混用**：两者差 3–5 单位，报告不注明就不可比。
3. **压头未垂直**或压在圆角、唇口上，读数偏低。
4. **未校准**：硬度计弹簧疲劳，系统性偏差被当成"批间波动"。
5. **把 Shore A 与 Shore D / IRHD 直接换算**：只能近似，不能作为判定依据。
6. **只测初始硬度、不测老化后**：装车 2 年后渗漏，根因常在这里。

### 10. 延伸到当前产品与技术方向

- **Fortrex**（库博标准轻量化密封材料平台）：以更低密度实现目标密封力，硬度设计需与**轻量化 + 低压缩负荷**联动，硬度常略低于传统 EPDM 密实胶。
- **FlexiFit / FlexiCore**（可变断面/柔性骨架类密封方案）：断面柔性靠**结构**而非单纯降硬度，因此硬度公差可适度放宽、靠几何补偿。
- 电动车（EV）方向：风噪要求高 → 密封力↑，但关门力与续航（重量）要求↓，**硬度-断面-材料**三者必须联合优化，硬度单点优化会失败。
- 海绵泡管 + 密实胶复合挤出（dual durometer / co-extrusion）：同一断面两个硬度，图纸须**分区标注**，测试须**分区取样**。

### 11. 自测 5 题

1. 图纸写 `70 ± 5 Shore A, ASTM D2240`，还缺哪三项关键信息？
2. 试样厚度只有 4 mm，正确做法是什么？不这么做会怎样？
3. 某批硬度均值合格但极差 8，是否放行？依据是什么？
4. 硬度从 70 降到 62，列出两条可能的性能后果。
5. 老化后硬度上升 10 单位，最可能的原因是什么？对密封有何影响？

### 参考答案

1. 缺：**读数方式**（1 s 瞬时还是 15 s 延迟）、**试样与取样位置**（成品断面还是标准试片、是否叠层）、**老化后要求**（老化条件与硬度变化限值）。此外校准与取值规则（5 点中位数）也应写明。
2. 正确做法：**叠层至 ≥6 mm**（同材质、表面贴合、无气隙），或改用微型硬度计并注明方法。不叠层会导致读数**偏高且离散大**，把合格件判成超差，或掩盖真实偏低。
3. **不放行，先复测**。取值规则要求 5 点中位数且**极差 ≤5**；极差 8 说明试样表面不均、硫化不均或测量手法有问题。应换点复测、检查硫化与压头垂直度，确认后再判定。
4. ①压缩负荷下降 → 长期密封力不足、老化后渗漏风险↑；②抗撕裂与耐磨下降 → 装配或使用中唇口破损；同时可能伴随增塑剂偏多，老化后硬度回升、尺寸不稳。
5. 最可能：**增塑剂挥发/迁移**或**后硫化/继续交联**。影响：密封条变硬 → 柔顺性下降、贴合变差、关门力升高，同时压缩永久变形恶化，长期密封能力衰减。
