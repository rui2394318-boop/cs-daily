**6 个最容易用错的词：**

1. **cure** — “The parts are cured at 180 degrees for 8 minutes.” 中国人常说 “the parts are vulcanized” 但口语里老板几乎总说 **cure**；另外 cure 也可指“解决问题”，别说 “cure the issue” 在正式会上，改 “fix / resolve the issue”。
2. **compound** — “We changed the compound to improve compression set.” 中国人容易把 compound 和 material 混用；**compound = 胶料配方**，说 “the material” 太泛，老板会追问 “which compound?”
3. **formulation** — “This is a new formulation for the B-pillar seal.” 中国人常错说 “recipe”（更像做饭），工程上统一用 **formulation**。
4. **batch** — “The first batch failed the hardness test.” 中国人常说 “the first lot”，可以，但**batch** 更常用；注意别说 “one batch of product” 啰嗦，直接 “the first batch”。
5. **align** — “Let's align on the test plan before Friday.” 中国人常错用 “reach agreement”，太正式；口语会议里 **align on** 最自然。别写 “align with each other”。
6. **blocker** — “The main blocker is the plasticizer supply.” 中国人爱说 “problem / difficulty”，但会议上说 **blocker** 更有力度，老板一听就知道要决策。

## Part 3 连词与连接词 6 个（4 分钟）

| 连词 | 作用 | 例句 | 中国人常犯的错 |
|---|---|---|---|
| however | 转折（书面/正式口语） | The hardness is OK; however, compression set is too high. | 放句首后忘加逗号；口语里连说 “however” 显得生硬，会议中用 “but” 更自然，正式总结才用 however |
| whereas | 对比两件事 | EPDM is cheaper, whereas TPV is easier to recycle. | 中国人常拿来当 “while” 随便用；whereas 必须两边真对比，不能只说一边 |
| therefore | 因此（因果） | The batch failed, therefore we need a new formulation. | 口语里过度使用，显得像写论文；会议中更常说 “so” |
| as long as | 只要（条件） | We can ship Friday as long as the cure test passes. | 后面常错接 will：“as long as it will pass” ❌，要接一般现在时 |
| unless | 除非 | We won't change the compound unless the customer asks. | 中国人常和 “if not” 混，且忘主句否定逻辑 |
| due to | 由于（后接名词） | The delay is due to a plasticizer shortage. | 错说 “due to the test failed”，due to 后必须接名词/名词短语 |

**三句串成一段连贯汇报：**
“The trial batch passed the hardness test. **However**, compression set is still above spec. **Therefore**, we need to adjust the curing agent level, **unless** the customer accepts the current value.”

## Part 4 法国口音听力训练（8 分钟，重点）

### 4.1 法国人说英语的发音特征

| 特征 | 他会说成 | 你要听成 | 例子 |
|---|---|---|---|
| h 音脱落 / 乱加 | 'ardness / 'eavy；有时在元音前乱加 h | hardness / heavy | “the 'ardness is too 'igh” = the hardness is too high |
| th 变 s / z | sink / zis | think / this | “I sink zis batch is OK” = I think this batch is OK |
| 词尾重音 | comPOund、forMUlation 重音后移 | COMpound、formuLAtion | “the comPOUND is new” |
| /r/ 小舌音 | 喉音 r，像法语 “r” | 仍按 r 理解 | “cure” 听起来像 “cu-e” |
| /ɪ/ 与 /iː/ 不分 | sit / seat 都像 “see-t” | 靠上下文判断 | “a bit” 和 “a beat” 难分 |
| -ing 读成 -ingg | meetingg、curingg | meeting / curing | “the curingg time” |
| v / w 混淆 | “wery” = very；“ve” = we | 靠句子逻辑还原 | “it's wery important” |
| 词尾辅音吞掉 | “tes” = test；“bat” = batch | test / batch | “the firs bat failed” |
| 数字读法 | fifteen / fifty 重音不清 | 靠上下文（时间/数量）判断 | “in fifteen minutes” vs “in fifty minutes” |

### 4.2 三个高频句的「他说的 → 你听的」对照

**句 1** 原句：*I think we have a problem with the hardness on the B-pillar.*
他大概会说：*“I sink we 'ave a problem wiz ze 'ardness on ze B-pillar.”*
你怎么还原：听到 “sink” → think；听到 “wiz ze” → with the；听到 “'ardness” → hardness（h 脱落）。抓住关键词 **problem + hardness + B-pillar** 就能懂整句。

**句 2** 原句：*The compression set is still too high after curing.*
他大概会说：*“Ze compression set is still too 'igh after curingg.”*
你怎么还原：“Ze” → the；“'igh” → high；结尾 “curingg” → curing。关键词 **compression set / high / curing**。

**句 3** 原句：*Can you check the plasticizer level in the next batch?*
他大概会说：*“Can you check ze plasticizer level in ze next batch?”*
你怎么还原：连续两个 “ze” 都是 the；plasticizer 重音后移成 “plasticiZER”，别被带跑；batch 词尾可能吞成 “bat”，靠 “next” 判断。

### 4.3 假朋友（faux amis）

| 他会用的词 | 他其实想表达 | 你要怎么理解 |
|---|---|---|
| actually | 法语 actuellement = 目前、当前 | 他说 “actually” 常是“目前”，不是“实际上” |
| eventually | 法语 éventuellement = 可能、也许 | 不是“最终”，而是“有可能” |
| assist (at) | 法语 assister à = 出席、参加 | “I assisted the meeting” = 我参加了会议，不是“协助” |
| delay | 法语 délai = 期限、时限 | “what's the delay?” 可能是问“截止时间”，不是“延误” |
| control | 法语 contrôler = 检查、核对 | “we need to control the batch” = 检查批次，不是“控制” |
| formation | 法语 formation = 培训 | “a formation on EPDM” = 一场培训，不是“形成” |
| sensible | 法语 sensible = 敏感 | “this is sensible” 可能是“这个很敏感”，不是“合理” |

### 4.4 一段模拟对话

**老板（法式）**：*“OK, let's start. First point on ze agenda — ze 'ardness on ze B-pillar.”*（标准：OK, let's start. First point on the agenda — the hardness on the B-pillar.）
**你**：Sorry, just to make sure I got that — you mean the hardness result on the B-pillar?

**老板**：*“Yes. Ze firs bat was too 'igh, almost seventy-five.”*（标准：Yes. The first batch was too high, almost seventy-five.）
**你**：Got it, the first batch was around 75. Was that after curing?

**老板**：*“After curingg, yes. I sink ze plasticizer level is not right.”*（标准：After curing, yes. I think the plasticizer level is not right.）
**你**：Understood — you think the plasticizer level may be off. Can I confirm the target level before we change the formulation?

**老板**：*“Sixty. And check ze carbon black loading too.”*（标准：Sixty. And check the carbon black loading too.）
**你**：So sixty for plasticizer, and I'll also check the carbon black loading. Correct?

**老板**：*“Correct. Can you send me ze data by Wednesday?”*（标准：Correct. Can you send me the data by Wednesday?）
**你**：Yes, by Wednesday. Just to be clear — do you want the raw data or a short summary?

**老板**：*“A short summary is fine. Let's wrap up — action items: you check ze compound, I loop in ze supplier.”*（标准：A short summary is fine. Let's wrap up — action items: you check the compound, I loop in the supplier.）
**你**：Perfect. To confirm: I check the compound and send the summary by Wednesday, and you loop in the supplier. Thanks everyone.

## Part 5 输出任务（2 分钟）

**任务 1（开口录音）**：录一段 60 秒的会议开场 + 收尾，必须包含下面三句，念到自然、不卡：
- “OK, if everyone's ready, let's kick off. The agenda today is the hardness issue on the B-pillar.”
- “Sorry to jump in — just to make sure I got that right, you mean the first batch was around 75 after curing?”
- “So to confirm: I'll check the compound and send a short summary by Wednesday, and you'll loop in the supplier. Thanks everyone.”
**检查点**：回放时听自己有没有 ① 每句都有清晰重音；② 没有把 “curing” 念成 “curingg”；③ 三句之间没有长时间 “呃…”。

**任务 2（写）**：用英文写 3–5 句会议纪要，包含：一个硬度问题、一个配方调整（plasticizer 或 carbon black）、一个 action item 和截止时间。至少用上 **however / therefore / as long as** 中的两个。
**检查点**：① 是否写清了“谁在什么时候做什么”；② 连词是否用得逻辑正确（不是硬塞）；③ 有没有把 compound / formulation / batch 用对。写完后自己读一遍，能一口气讲出来就算过关。
